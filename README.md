
# Healthcare Analytics Decision Brief

## Project Overview
This project focuses on analysing healthcare patient data, pharmacy sales and adverse drug reactions using Python.

## Objectives
- Analyse patient readmission patterns.
- Understand pharmacy sales performance.
- Identify common adverse drug reactions.
- Visualise healthcare data for better understanding.

## Technologies Used
- Python
- Google Colab
- Pandas
- Matplotlib
- Seaborn
- GitHub

## Project Activities

### 1. Patient Data Analysis
- Data cleaning
- Readmission analysis
- Age-wise analysis
- Diagnosis-wise analysis

### 2. Pharmacy Sales Analysis
- Medicine-wise sales analysis
- Category-wise sales analysis
- Monthly sales trends
- Data visualisation

### 3. Adverse Drug Reaction Analysis
- Drug-wise reporting
- Reaction-wise reporting
- Severity distribution
- Patient outcome analysis

## Project Outputs
- Healthcare data visualisations
- Patient analysis
- Pharmacy sales analysis
- Four aggregate CSV files

## Conclusion
This project demonstrates how Python-based data analytics can help understand healthcare trends, pharmacy performance and adverse drug reaction reports.

## Note
The datasets used in this project are sample datasets. The findings are for educational and analytical purposes only.
